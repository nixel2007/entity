# Работа над entity

## Порядок работы

- **Сначала тесты, потом реализация.** Тест пишется до кода, который он проверяет,
  и должен падать на текущем поведении. Это относится и к исправлениям дефектов:
  сперва тест, воспроизводящий дефект, затем починка.
- **Правки кода — только файловыми инструментами** (Read/Edit/Write). Редактировать
  исходники через `sed`, `python`, `cat >> файл` и прочие перенаправления оболочки
  нельзя без явного разрешения.

## Прогон тестов

```
opm install opm@1.0.2
opm install -l
opm install -l --dev
./oscript_modules/bin/oneunit execute
```

Тесты гоняет [oneunit](https://github.com/sfaqer/oneunit). Переменные среды
`TESTRUNNER_RUN_SQLITE_TESTS` и `TESTRUNNER_RUN_POSTGRES_TESTS` — единственный
способ сказать, какие базы доступны. Наборы, которым нужна конкретная база,
выключаются аннотацией `&ВключенЕсли`, читающей ту же переменную; наборы,
работающие с любой из двух, выбирают по ним базу сами.
