## НаблюдательСущностей

Интерфейс наблюдателя сущностей.

Наблюдатель получает события работы менеджера сущностей: операции (Сохранить, Получить,
ПолучитьОдно, Удалить, Инициализировать, ВыполнитьСКоннектором, ВычислитьСКоннектором),
запросы к СУБД, захват и освобождение соединений пула, транзакции. Каждое событие приходит
дважды: до выполнения и после, одним и тем же объектом [СобытиеСущностей](СобытиеСущностей.md).

Реализация объявляет интерфейс аннотацией `&Реализует("НаблюдательСущностей")` на конструкторе
и регистрируется на менеджере методом `ДобавитьНаблюдателя`. Регистрация проверяет реализацию
через `ВалидаторРеализации` библиотеки extends, поэтому неполная реализация отвергается сразу.

Наблюдатель вызывается из разных потоков исполнения одновременно и не должен держать
несинхронизированного общего состояния: все, что нужно между фазами, кладется в событие
методом `УстановитьСостояние`. Исключение наблюдателя пишется в лог и операцию не прерывает.

Подробнее - в разделе [Наблюдатели сущностей](Наблюдатели.md).

### ПриСозданииОбъекта

```bsl
// Пример:
//   &Реализует("НаблюдательСущностей")
//   Процедура ПриСозданииОбъекта()
//   КонецПроцедуры
//
//   Процедура ПередСобытием(Событие) Экспорт
//       Событие.УстановитьСостояние(ТекущаяУниверсальнаяДатаВМиллисекундах());
//   КонецПроцедуры
//
//   Процедура ПослеСобытия(Событие) Экспорт
//       Сообщить(СтрШаблон("%1 %2: %3 мс", Событие.Вид(), Событие.Операция(), Событие.Длительность()));
//   КонецПроцедуры
//
&Интерфейс
Процедура ПриСозданииОбъекта()
```

### ПередСобытием

```bsl
// Вызывается перед выполнением события.
//
// Параметры:
//   Событие - СобытиеСущностей - Начатое событие. Поля результата еще не заполнены.
//
Процедура ПередСобытием(Событие) Экспорт
```

### ПослеСобытия

```bsl
// Вызывается после выполнения события, в том числе завершившегося ошибкой.
//
// Параметры:
//   Событие - СобытиеСущностей - Завершенное событие: заполнены Длительность, Ошибка и поля результата.
//
Процедура ПослеСобытия(Событие) Экспорт
```
