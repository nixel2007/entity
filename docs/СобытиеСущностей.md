## СобытиеСущностей

Событие работы менеджера сущностей, передаваемое наблюдателям.

Один и тот же объект приходит наблюдателю дважды: в `ПередСобытием`, когда заполнены только
описательные поля, и в `ПослеСобытия`, когда заполнены длительность, ошибка и поля результата.
Поля читаются функциями; менять их наблюдателю не следует. Для своих данных между фазами
у наблюдателя есть `Состояние` - у каждого наблюдателя свое, чужого он не видит.

Виды событий - значения перечисления [ВидыСобытийСущностей](ВидыСобытийСущностей.md). Заполняемые поля:

* Операция - операция менеджера или хранилища: Операция, ТипСущности, ИмяТаблицы, Глубина;
  после - КоличествоСтрок для чтения.
* Запрос - запрос к СУБД: Операция (SELECT, INSERT, DELETE, CREATE TABLE, BEGIN, COMMIT,
  ROLLBACK), ИмяТаблицы, ТекстЗапроса (Неопределено у коннекторов без SQL); после - КоличествоСтрок.
* Соединение - захват и освобождение соединения пула: Операция (Занять, Освободить); после -
  Ожидание, Открыто, ВремяОткрытия и снимок пула: Занято, Свободно, Ожидает, Предел.
* Транзакция - транзакция потока исполнения: после - Исход (commit, rollback, failed, abandoned).

Методы с пометкой `@internal` заполняют событие изнутри библиотеки.

Подробнее - в разделе [Наблюдатели сущностей](Наблюдатели.md).

### ПриСозданииОбъекта

```bsl
// Создает начатое событие.
//
// Создается библиотекой, напрямую конструировать не следует.
//
// Параметры:
//   ПВид - Строка - Вид события, значение перечисления ВидыСобытийСущностей.
//   ПОперация - Строка - Операция события.
//   ПГлубина - Число - Вложенность операции.
//
Процедура ПриСозданииОбъекта(Знач ПВид, Знач ПОперация, Знач ПГлубина = 0)
```

```bsl

// события его не видят и не затирают.

//   Значение - Произвольный - Данные наблюдателя, например открытый спан.
```
