## Потокобезопасные транзакции

### Проблема

Раньше менеджер сущностей работал одним коннектором на все потоки. Транзакция была
свойством коннектора, а не того, кто ее начал, поэтому фоновые задания завершали транзакции друг
друга:

```bsl
// Основной поток
МенеджерСущностей.НачатьТранзакцию();
МенеджерСущностей.Сохранить(Сущность);

// Фоновое задание в это же время
МенеджерСущностей.НачатьТранзакцию();
МенеджерСущностей.ЗафиксироватьТранзакцию(); // Фиксирует и запись основного потока
```

### Решение

Менеджер выдает каждому контексту исполнения собственное соединение из пула. Контекст - это
фоновое задание, а вне фоновых заданий - основной поток. Соединение закрепляется за контекстом в
`НачатьТранзакцию` и возвращается в пул в `ЗафиксироватьТранзакцию` или `ОтменитьТранзакцию`.
Пока соединение закреплено, все операции контекста идут по нему - и через менеджер, и через
хранилища сущностей.

Передавать что-либо между вызовами не нужно: контекст определяется автоматически.

```bsl
// Основной поток
МенеджерСущностей.НачатьТранзакцию();
МенеджерСущностей.Сохранить(Сущность);

// Фоновое задание работает своим соединением и своей транзакцией
МенеджерСущностей.НачатьТранзакцию();
МенеджерСущностей.ЗафиксироватьТранзакцию(); // Записи основного потока не касается

МенеджерСущностей.ОтменитьТранзакцию(); // Отменяет только свою запись
```

### Размер пула

Размер пула задается четвертым параметром конструктора и по умолчанию равен 10:

```bsl
МенеджерСущностей = Новый МенеджерСущностей(
    Тип("КоннекторPostgreSQL"),
    "Host=localhost;Port=5432;Database=test",
    Неопределено,
    10
);
```

Размер пула - это то, сколько соединений придерживается для переиспользования, а не предел
одновременно живущих. В выдаче пул не отказывает никогда: контексту, которому соединения не
хватило, открывается новое, и оно закрывается сразу после освобождения.

Поэтому нулевой размер не отключает пул и не возвращает поведение до потокобезопасных транзакций.
Он отключает только переиспользование: каждая транзакция открывает свое соединение и закрывает
его по завершении. Собственное соединение контекст получает при любом размере пула.

```bsl
МенеджерСущностей = Новый МенеджерСущностей(Тип("КоннекторSQLite"), СтрокаСоединения, Неопределено, 0);
```

### Незавершенные транзакции

Если фоновое задание завершилось, не зафиксировав и не отменив транзакцию, его соединение остается
закрепленным за уже несуществующим контекстом. Такие соединения пул отбирает у завершившихся
контекстов, когда свободных не осталось: незавершенная транзакция откатывается, а соединение
уходит следующему контексту.

Это страховка, а не штатный режим. Транзакцию следует завершать явно:

```bsl
МенеджерСущностей.НачатьТранзакцию();
Попытка
    МенеджерСущностей.Сохранить(Сущность);
    МенеджерСущностей.ЗафиксироватьТранзакцию();
Исключение
    МенеджерСущностей.ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;
```

### Закрытие

`МенеджерСущностей.Закрыть()` закрывает все соединения пула, в том числе закрепленные за
контекстами.
