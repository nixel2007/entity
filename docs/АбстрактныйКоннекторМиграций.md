# АбстрактныйКоннекторМиграций

Описание дополнительного интерфейса коннектора, поддерживающего миграции схемы БД.

Коннектор, реализующий данный интерфейс в дополнение к интерфейсу
[АбстрактныйКоннектор](АбстрактныйКоннектор.md), участвует в автоматических миграциях схемы,
выполняемых [МиграторомСхемы](МиграторСхемы.md). Для коннектора без поддержки данного
интерфейса мигратор выполняет обычную инициализацию таблиц через `ИнициализироватьТаблицу`,
сохраняя обратную совместимость со сторонними коннекторами.

Интерфейс реализован всеми коннекторами библиотеки:

* `КоннекторSQLite` — интроспекция через `pragma_table_info`; добавление колонок через
  `ALTER TABLE ADD COLUMN`; изменение типа и удаление колонок — перестроением таблицы
  с переносом данных общих колонок;
* `КоннекторPostgreSQL` — интроспекция через системный каталог (`pg_attribute` + `to_regclass`);
  изменения применяются операторами `ALTER TABLE`;
* `КоннекторJSON` — список колонок вычисляется объединением ключей сохраненных строк;
  добавление и удаление колонок переписывает строки файла таблицы;
* `КоннекторInMemory` — сущности хранятся экземплярами актуального класса,
  схема существующей таблицы всегда соответствует модели.

### ПолучитьОписаниеТаблицы

```bsl
// Возвращает описание фактической схемы таблицы в БД.
//
// Параметры:
//   ОбъектМодели - ОбъектМодели - Объект, содержащий описание класса-сущности и настроек таблицы БД.
//
//  Возвращаемое значение:
//   ОписаниеТаблицы - Описание фактического состояния таблицы в БД.
//       Если таблица отсутствует, свойство Существует() описания возвращает Ложь.
//
Функция ПолучитьОписаниеТаблицы(ОбъектМодели) Экспорт
```

### ПрименитьИзмененияТаблицы

```bsl
// Применяет изменения схемы одной таблицы.
//
// Все переданные изменения относятся к таблице переданного объекта модели и применяются
// одним вызовом, чтобы коннектор мог выбрать оптимальную стратегию применения
// (например, однократное перестроение таблицы в SQLite).
//
// Параметры:
//   ОбъектМодели - ОбъектМодели - Объект, содержащий описание класса-сущности и настроек таблицы БД.
//   ИзмененияСхемы - Массив - Массив объектов ИзменениеСхемы для таблицы объекта модели.
//
Процедура ПрименитьИзмененияТаблицы(ОбъектМодели, ИзмененияСхемы) Экспорт
```

### ПолучитьТипКолонкиСУБД

```bsl
// Возвращает тип колонки в терминах СУБД коннектора.
//
// Тип используется МиграторомСхемы для сравнения ожидаемого типа колонки с фактическим типом
// из ОписанияТаблицы. Для бессхемных коннекторов допустимо возвращать тип колонки модели
// (см. ТипыКолонок) при условии, что ПолучитьОписаниеТаблицы возвращает типы в тех же терминах.
//
// Параметры:
//   ОбъектМодели - ОбъектМодели - Объект, содержащий описание класса-сущности и настроек таблицы БД.
//   КолонкаМодели - СтрокаТаблицыЗначений - Строка таблицы колонок объекта модели (см. ОбъектМодели.Колонки).
//
//  Возвращаемое значение:
//   Строка - Тип колонки в терминах СУБД коннектора.
//
Функция ПолучитьТипКолонкиСУБД(ОбъектМодели, КолонкаМодели) Экспорт
```
