# ВидыИзмененийСхемы

Виды изменений схемы БД, вычисляемые при сравнении модели данных с фактической схемой БД.
Используются в объектах [ИзменениеСхемы](ИзменениеСхемы.md).

Значения:

* `СозданиеТаблицы` - таблица отсутствует в БД и будет создана;
* `ДобавлениеКолонки` - колонка модели отсутствует в таблице БД и будет добавлена;
* `ИзменениеТипаКолонки` - тип колонки в БД отличается от типа колонки модели и будет изменен;
* `УдалениеКолонки` - колонка таблицы БД отсутствует в модели и будет удалена.
  Изменения этого вида попадают в план только при включенной опции
  `МиграторСхемы.УстановитьУдалениеЛишнихКолонок`.
