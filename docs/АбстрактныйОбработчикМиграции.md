# АбстрактныйОбработчикМиграции

Шаблон обработчика данных, вызываемого [МиграторомСхемы](МиграторСхемы.md) при обновлении схемы БД.

Обработчиком миграции может выступать любой объект. Все методы шаблона необязательны:
достаточно реализовать хотя бы один из методов `ПередМиграцией` / `ПослеМиграции`.
Обработчик регистрируется через `МенеджерСущностей.ДобавитьОбработчикМиграции`
или `МиграторСхемы.ДобавитьОбработчикМиграции`.

Пример обработчика, привязанного к версии схемы:

```bsl
// file: ЗаполнениеРейтингаАвторов.os

Функция ВерсияСхемы() Экспорт
	Возврат "1.2.0";
КонецФункции

Процедура ПослеМиграции(МенеджерСущностей, ПланМиграции) Экспорт
	Авторы = МенеджерСущностей.Получить(Тип("Автор"));
	Для Каждого Автор Из Авторы Цикл
		Если НЕ ЗначениеЗаполнено(Автор.Рейтинг) Тогда
			Автор.Рейтинг = 1;
			МенеджерСущностей.Сохранить(Автор);
		КонецЕсли;
	КонецЦикла;
КонецПроцедуры
```

### ВерсияСхемы

```bsl
// Возвращает версию схемы, к которой привязан обработчик.
//
// Обработчик с заполненной версией выполняется только при переходе хранимой версии схемы
// через эту версию: ХранимаяВерсия < ВерсияСхемы() <= ВерсияПриложения.
// При обновлении через несколько версий (например, с 0.1.0 сразу на 0.3.0) выполняются
// все обработчики, попавшие в интервал, в порядке возрастания версий (конвейер миграций).
// После выполнения обработчиков каждой промежуточной версии эта версия фиксируется
// в служебной таблице, поэтому прерванный конвейер продолжается со следующей версии.
//
// Обработчик с пустой версией выполняется при каждом обновлении схемы.
//
// Схема БД мигрирует к целевому состоянию за один шаг, поэтому обработчики всех версий
// работают с БД, уже приведенной к актуальной модели данных.
//
//  Возвращаемое значение:
//   Строка - Версия схемы в формате семантического версионирования ("МАЖОР.МИНОР.ПАТЧ"),
//       либо пустая строка, если обработчик не привязан к версии.
//
Функция ВерсияСхемы() Экспорт
```

### ПередМиграцией

```bsl
// Вызывается до применения изменений схемы.
//
// Параметры:
//   МенеджерСущностей - МенеджерСущностей - Менеджер сущностей, выполняющий миграцию.
//   ПланМиграции - ПланМиграции - План изменений схемы, которые будут применены.
//
Процедура ПередМиграцией(МенеджерСущностей, ПланМиграции) Экспорт
```
