## ЭлементОтбора

### Поля

| Имя          | Тип          |
| ------------ | ------------ |
| ПутьКДанным  | Строка       |
| ВидСравнения | ВидСравнения |
| Значение     | Произвольный |

Для видов сравнения `В` и `НеВ` в поле `Значение` хранится `Массив` значений.
Подробнее - [ВидСравнения](ВидСравнения.md#отбор-по-множеству-значений).
