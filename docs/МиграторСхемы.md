# МиграторСхемы

Выполняет автоматическую миграцию схемы БД при инициализации менеджера сущностей.

Мигратор сравнивает модель данных с фактической схемой БД, строит [ПланМиграции](ПланМиграции.md)
и применяет его через коннектор, реализующий интерфейс [АбстрактныйКоннекторМиграций](АбстрактныйКоннекторМиграций.md).
Для коннектора без поддержки этого интерфейса выполняется обычная инициализация таблиц
через `ИнициализироватьТаблицу`.

До и после применения изменений схемы вызываются зарегистрированные обработчики миграции
(см. [АбстрактныйОбработчикМиграции](АбстрактныйОбработчикМиграции.md)). При включенном
отслеживании версии схемы обработчики, привязанные к версиям, образуют конвейер: при обновлении
через несколько версий (например, с `0.1.0` сразу на `0.3.0`) они выполняются в порядке
возрастания версий, а каждая пройденная версия фиксируется в служебной таблице.

Экземпляр мигратора принадлежит менеджеру сущностей и настраивается до вызова
`МенеджерСущностей.Инициализировать()`:

```bsl
МенеджерСущностей = Новый МенеджерСущностей(Тип("КоннекторSQLite"), СтрокаСоединения);
МенеджерСущностей.ДобавитьКлассВМодель(Тип("Автор"));

МиграторСхемы = МенеджерСущностей.ПолучитьМиграторСхемы();
МиграторСхемы.УстановитьВерсиюСхемы("1.2.0");
МиграторСхемы.ДобавитьОбработчикМиграции(Новый ЗаполнениеРейтингаАвторов);

МенеджерСущностей.Инициализировать(); // анализ схемы, миграция, вызов обработчиков
```

### ПриСозданииОбъекта

```bsl
// Конструктор объекта МиграторСхемы.
//
// Параметры:
//   ПМенеджерСущностей - МенеджерСущностей - Менеджер сущностей, для которого выполняется миграция.
//
Процедура ПриСозданииОбъекта(Знач ПМенеджерСущностей)
```

### УстановитьВерсиюСхемы

```bsl
// Устанавливает версию схемы данных приложения и включает хранение версии схемы
// в служебной таблице (см. СлужебнаяСущность_ВерсияСхемы).
//
// При первой инициализации с включенным отслеживанием версия просто фиксируется в БД,
// обработчики, привязанные к версиям, при этом не выполняются.
// При последующих повышениях версии выполняется конвейер обработчиков (см. ДобавитьОбработчикМиграции).
// Понижение версии не поддерживается и приводит к исключению при инициализации.
//
// Параметры:
//   Версия - Строка - Версия схемы в формате семантического версионирования ("МАЖОР.МИНОР.ПАТЧ").
//       Недостающие компоненты версии дополняются нулями: "0.2" эквивалентно "0.2.0".
//
Процедура УстановитьВерсиюСхемы(Знач Версия) Экспорт
```

### УстановитьУдалениеЛишнихКолонок

```bsl
// Включает или выключает удаление из БД колонок, отсутствующих в модели данных.
//
// По умолчанию удаление выключено: лишние колонки сохраняются, а в журнал выводится предупреждение.
//
// Параметры:
//   Значение - Булево - Истина, если лишние колонки нужно удалять при миграции.
//
Процедура УстановитьУдалениеЛишнихКолонок(Знач Значение) Экспорт
```

### ДобавитьОбработчикМиграции

```bsl
// Регистрирует обработчик данных, вызываемый при обновлении схемы БД.
//
// Обработчик должен реализовывать хотя бы один из методов ПередМиграцией / ПослеМиграции
// (см. АбстрактныйОбработчикМиграции). Если обработчик реализует метод ВерсияСхемы,
// возвращающий непустую версию, он выполняется только при переходе хранимой версии схемы
// через эту версию. Обработчики нескольких версий выполняются в порядке возрастания версий
// независимо от порядка регистрации; несколько обработчиков одной версии выполняются
// в порядке регистрации.
//
// Параметры:
//   Обработчик - Произвольный - Регистрируемый обработчик миграции.
//
Процедура ДобавитьОбработчикМиграции(Знач Обработчик) Экспорт
```

### ВыполнитьМиграцию

```bsl
// Выполняет миграцию схемы БД.
//
// Вызывается менеджером сущностей при инициализации. Порядок выполнения:
//   1. Инициализация служебной таблицы версии схемы и чтение хранимой версии (при отслеживании версии);
//   2. Построение плана миграции сравнением модели данных с фактической схемой БД;
//   3. Вызов методов ПередМиграцией обработчиков;
//   4. Применение плана миграции;
//   5. Вызов методов ПослеМиграции обработчиков с фиксацией каждой пройденной версии конвейера;
//   6. Фиксация версии схемы приложения.
//
Процедура ВыполнитьМиграцию() Экспорт
```
