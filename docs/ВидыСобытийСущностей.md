## ВидыСобытийСущностей

Виды событий, которые менеджер сущностей отдает наблюдателям, см. `Вид()` у
[СобытиеСущностей](СобытиеСущностей.md). Наблюдатель сравнивает вид события со значениями
перечисления, а не со строковыми литералами:

```bsl
Если Событие.Вид() = ВидыСобытийСущностей.Запрос Тогда
```

### Значения

* Операция - операция менеджера или хранилища: Сохранить, Получить, Удалить и другие.
* Запрос - запрос коннектора к СУБД: SELECT, INSERT, DELETE, CREATE TABLE, BEGIN, COMMIT, ROLLBACK.
* Соединение - захват и освобождение соединения пула: Занять, Освободить.
* Транзакция - транзакция потока исполнения от начала до исхода.

### Виды

```bsl
// Все виды событий в порядке объявления.
//
// Возвращаемое значение:
//   Массив из Строка - Операция, Запрос, Соединение, Транзакция.
//
Функция Виды() Экспорт
```
