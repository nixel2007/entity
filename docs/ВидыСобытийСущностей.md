## ВидыСобытийСущностей

Виды событий, которые менеджер сущностей отдает наблюдателям, см. `Вид()` у
[СобытиеСущностей](СобытиеСущностей.md). Значения отдаются функциями, а не экспортными
переменными, чтобы их нельзя было изменить извне. Наблюдатель сравнивает вид события с ними,
а не со строковыми литералами:

```bsl
Если Событие.Вид() = ВидыСобытийСущностей.Запрос() Тогда
```

### Операция

```bsl
// Операция менеджера или хранилища: Сохранить, Получить, Удалить и другие.
//
// Возвращаемое значение:
//   Строка - Вид события операции.
//
Функция Операция() Экспорт
```

// Запрос коннектора к СУБД: SELECT, INSERT, DELETE, CREATE TABLE, BEGIN, COMMIT, ROLLBACK.
