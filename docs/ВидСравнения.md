## ВидСравнения

Значения:

| Значение         | Тип значения отбора |
| ---------------- | ------------------- |
| Равно            | Произвольный        |
| Больше           | Произвольный        |
| БольшеИлиРавно   | Произвольный        |
| Меньше           | Произвольный        |
| МеньшеИлиРавно   | Произвольный        |
| НеРавно          | Произвольный        |
| В                | Массив              |
| НеВ              | Массив              |

### Отбор по множеству значений

Виды сравнения `В` и `НеВ` проверяют вхождение значения поля в множество значений.
Множество передается [`ОпцииПоиска.Отбор`](ОпцииПоиска.md#отбор) массивом:

```bsl
МассивИмен = Новый Массив;
МассивИмен.Добавить("Иван");
МассивИмен.Добавить("Петр");

ОпцииПоиска = Новый ОпцииПоиска()
  .Отбор("Имя", ВидСравнения.В, МассивИмен);
```

Пустой массив — допустимое множество, и результат для него следует семантике пустого множества
в ANSI SQL: `В` не отбирает ни одной строки, `НеВ` отбирает все. Поведение одинаково у всех
коннекторов.

Для остальных видов сравнения значением отбора является одиночное значение,
соответствующее типу колонки.
