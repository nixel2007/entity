# ОписаниеТаблицы

Описание фактической схемы таблицы БД, полученное от коннектора
(см. [АбстрактныйКоннекторМиграций](АбстрактныйКоннекторМиграций.md)).
Используется [МиграторомСхемы](МиграторСхемы.md) для сравнения фактической схемы таблицы
с моделью данных.

### ПриСозданииОбъекта

```bsl
// Конструктор объекта ОписаниеТаблицы.
//
// Параметры:
//   ПИмяТаблицы - Строка - Имя описываемой таблицы.
//   ПСуществует - Булево - Признак существования таблицы в БД.
//
Процедура ПриСозданииОбъекта(Знач ПИмяТаблицы, Знач ПСуществует = Ложь)
```

### ИмяТаблицы

```bsl
// Возвращает имя описываемой таблицы.
//
//  Возвращаемое значение:
//   Строка - Имя таблицы.
//
Функция ИмяТаблицы() Экспорт
```

### Существует

```bsl
// Возвращает признак существования таблицы в БД.
//
//  Возвращаемое значение:
//   Булево - Истина, если таблица существует в БД.
//
Функция Существует() Экспорт
```

### Колонки

```bsl
// Возвращает описания колонок таблицы.
//
//  Возвращаемое значение:
//   ТаблицаЗначений - Колонки таблицы:
//     * ИмяКолонки - Строка - Имя колонки.
//     * ТипКолонкиСУБД - Строка - Тип колонки в терминах СУБД коннектора.
//
Функция Колонки() Экспорт
```

### ДобавитьКолонку

```bsl
// Добавляет описание колонки таблицы.
//
// Параметры:
//   ПИмяКолонки - Строка - Имя колонки.
//   ПТипКолонкиСУБД - Строка - Тип колонки в терминах СУБД коннектора.
//
Процедура ДобавитьКолонку(Знач ПИмяКолонки, Знач ПТипКолонкиСУБД = "") Экспорт
```

### НайтиКолонку

```bsl
// Ищет описание колонки по имени без учета регистра.
//
// Параметры:
//   ПИмяКолонки - Строка - Имя искомой колонки.
//
//  Возвращаемое значение:
//   СтрокаТаблицыЗначений, Неопределено - Описание колонки (см. Колонки), если колонка найдена.
//
Функция НайтиКолонку(Знач ПИмяКолонки) Экспорт
```
