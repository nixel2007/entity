## МодельДанных

Модель общая у всех потоков, работающих с менеджером: операции читают ее на каждом шаге, а классы
можно регистрировать и после передачи менеджера другим потокам.

### ПриСозданииОбъекта

```bsl

Процедура ПриСозданииОбъекта() 
```

### Получить

```bsl
// Возвращает объект модели типа сущности.
//
// Параметры:
//   ТипСущности - Тип - Тип сущности.
//
// Возвращаемое значение:
//   ОбъектМодели - Объект модели типа.
//   Неопределено - Тип не зарегистрирован в модели.
//
Функция Получить(ТипСущности) Экспорт
```

### ПолучитьОбъектыМодели

```bsl
// Возвращает объекты модели всех зарегистрированных типов.
//
// Возвращаемое значение:
//   Массив из ОбъектМодели - Копия на момент вызова: типы, зарегистрированные позже, в нее не
//     попадут.
//
Функция ПолучитьОбъектыМодели() Экспорт
```

### СоздатьОбъектМодели

```bsl
// Регистрирует тип сущности в модели.
//
// Если тип уже зарегистрирован, возвращается существующий объект модели: с ним уже могут работать
// хранилища и операции других потоков, поэтому он не подменяется.
//
// Параметры:
//   ТипСущности - Тип - Тип сущности.
//
// Возвращаемое значение:
//   ОбъектМодели - Объект модели типа.
//
Функция СоздатьОбъектМодели(ТипСущности) Экспорт
```
