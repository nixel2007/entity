# ИзменениеСхемы

Одно изменение схемы БД, входящее в [ПланМиграции](ПланМиграции.md).

Поля объекта:

* `Вид` - Строка - Вид изменения схемы, см. [ВидыИзмененийСхемы](ВидыИзмененийСхемы.md);
* `ОбъектМодели` - [ОбъектМодели](ОбъектМодели.md) - Объект модели, к таблице которого относится изменение;
* `ИмяТаблицы` - Строка - Имя изменяемой таблицы;
* `ИмяКолонки` - Строка - Имя изменяемой колонки. Для вида `СозданиеТаблицы` не заполняется;
* `ТипКолонкиСУБД` - Строка - Целевой тип колонки в терминах СУБД коннектора.
  Заполняется для видов `ДобавлениеКолонки` и `ИзменениеТипаКолонки`.

### ПриСозданииОбъекта

```bsl
// Конструктор объекта ИзменениеСхемы.
//
// Параметры:
//   ПВид - Строка - Вид изменения схемы, см. ВидыИзмененийСхемы.
//   ПОбъектМодели - ОбъектМодели - Объект модели, к таблице которого относится изменение.
//   ПИмяКолонки - Строка - Имя изменяемой колонки. Для вида СозданиеТаблицы не заполняется.
//   ПТипКолонкиСУБД - Строка - Целевой тип колонки в терминах СУБД коннектора.
//       Заполняется для видов ДобавлениеКолонки и ИзменениеТипаКолонки.
//
Процедура ПриСозданииОбъекта(Знач ПВид, Знач ПОбъектМодели, Знач ПИмяКолонки = "", Знач ПТипКолонкиСУБД = "")
```
