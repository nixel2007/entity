## АктивнаяЗапись

Сущность, созданная менеджером (`СоздатьЭлемент`) или прочитанная из базы, — запись с методами сохранения, чтения и удаления себя.

Тип записи регистрируется в системе типов один раз на тип сущности под именем `ЗаписьСущности_<ТипСущности>`: у всех записей одного типа сущности один и тот же тип, `ТипЗнч(Запись)` возвращает его, а не `Сценарий`. Исходный тип сущности дает `АктивнаяЗапись.ТипСущности(Запись)`. Хранилище и модель данных запись получает от создавшего ее менеджера, поэтому записи разных менеджеров одного типа сущности сохраняются каждая в свой источник.

### Сохранить

```bsl
// Сохранить текущую сущность.
//
Процедура Сохранить()
```

### Прочитать

```bsl
// Прочитать текущую сущность. Для чтения у сущности должно быть заполнено поле, являющееся идентификатором.
//
Процедура Прочитать()
```

### Удалить

```bsl
// Удалить текущую сущность.
//
Процедура Удалить()
```
