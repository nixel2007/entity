## НаблюдаемыйКоннектор

Интерфейс коннектора, умеющего сообщать наблюдателям сущностей о запросах к СУБД.

Дополняет [АбстрактныйКоннектор](АбстрактныйКоннектор.md), а не заменяет его: коннектор без
этого интерфейса работает как раньше, только наблюдатели не получают событий уровня запроса и
описания соединения. Встроенные коннекторы объявляют оба интерфейса аннотацией `&Реализует`
на конструкторе.

Пул соединений после открытия коннектора передает ему реестр наблюдателей и запрашивает
описание соединения. Описание никогда не содержит секретов: пароль из строки соединения
в него не попадает.

Подробнее - в разделе [Наблюдатели сущностей](Наблюдатели.md).

### ПриСозданииОбъекта

```bsl
// Пример:
//   &Реализует("АбстрактныйКоннектор")
//   &Реализует("НаблюдаемыйКоннектор")
//   Процедура ПриСозданииОбъекта()
//   КонецПроцедуры
//
&Интерфейс
Процедура ПриСозданииОбъекта()
```

### УстановитьНаблюдателей

```bsl
// Передает коннектору реестр наблюдателей, которым он сообщает о запросах.
//
// Параметры:
//   Наблюдатели - НаблюдателиСущностей - Реестр наблюдателей пула. Коннектор создает события через
//     НачатьЗапрос и завершает через ЗавершитьЗапрос; при пустом реестре события не создаются.
//
Процедура УстановитьНаблюдателей(Наблюдатели) Экспорт
```

### ОписаниеСоединения

```bsl
// Описывает соединение для атрибутов событий.
//
// Возвращаемое значение:
//   Структура - Описание соединения без секретов:
//     * Система - Строка - СУБД: postgresql, sqlite, inmemory, json.
//     * Адрес - Строка - Адрес сервера; пустая строка, если сервера нет.
//     * Порт - Число - Порт сервера; 0, если сервера нет.
//     * БазаДанных - Строка - Имя базы, путь к файлу или каталогу.
//
Функция ОписаниеСоединения() Экспорт
```
