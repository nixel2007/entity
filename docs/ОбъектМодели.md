## ОбъектМодели

### ПриСозданииОбъекта

```bsl
// Создает объект модели по аннотациям класса сущности.
//
// Параметры:
//   ПТипСущности - Тип - Тип класса сущности.
//   ПМодельДанных - МодельДанных - Модель, к которой относится объект.
//   ПИмяТаблицы - Строка - Имя таблицы вместо имени из аннотации класса. Так создаются объекты
//     модели подчиненных таблиц: класс элемента у них один, а таблицы разные.
//               - Неопределено - Имя таблицы берется из аннотации класса.
//
Процедура ПриСозданииОбъекта(ПТипСущности, ПМодельДанных, ПИмяТаблицы = Неопределено) 
```

### Колонки

```bsl
// Возвращает таблицу колонок модели.
//
// Объект модели общий у всех потоков, работающих с менеджером, поэтому отдается копия: ее можно
// менять, модель от этого не изменится.
//
// Возвращаемое значение:
//   ТаблицаЗначений - Копия колонок модели.
//
Функция Колонки() Экспорт
```
