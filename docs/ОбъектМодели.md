### Колонки

```bsl
// Возвращает таблицу колонок модели - саму таблицу, а не копию.
//
// Объект модели читают многие потоки, поэтому таблица только для чтения. Меняет ее лишь
// ОбработкаКоллекций, донастраивая только что созданный объект модели элемента коллекции,
// который другим потокам еще не виден.
//
// Возвращаемое значение:
//   ТаблицаЗначений - Колонки модели.
//
Функция Колонки() Экспорт
```
