## ИсточникДанных

Источник данных: имя, тип коннектора, строка соединения, параметры коннектора, размер пула
и сам пул соединений одним объектом.

Пул создается вместе с источником и общий для всех, кто работает через источник; соединения
пул открывает при первом обращении. Закрывает пул сам источник: методом `Закрыть()` или по
завершению потока, в котором источник создан, если автозакрытие не выключено, см.
`УстановитьАвтоЗакрытие`. Закрытие терминально: закрытый источник соединений не выдает.
Тип коннектора и размер пула проверяются при создании: тип без интерфейса
`АбстрактныйКоннектор` и отрицательный размер отвергаются с ошибкой.

```bsl
Источник = Новый ИсточникДанных("Основной", Тип("КоннекторPostgreSQL"), СтрокаСоединения, , 20);
```

### ПриСозданииОбъекта

```bsl
// Параметры:
//   Имя - Строка - Имя источника данных.
//   ТипКоннектора - Тип - Тип класса, реализующего интерфейс АбстрактныйКоннектор.
//   СтрокаСоединения - Строка - Строка соединения с БД.
//   ПараметрыКоннектора - Массив - Дополнительные параметры коннектора.
//   РазмерПула - Число - Предел одновременно живущих соединений с БД. Ноль снимает предел
//     и постоянно живущих соединений не держит.
//
Процедура ПриСозданииОбъекта(
	Знач Имя,
	Знач ТипКоннектора,
	Знач СтрокаСоединения = "",
	Знач ПараметрыКоннектора = Неопределено,
	Знач РазмерПула = 10
)
```

### УстановитьАвтоЗакрытие

```bsl
// Включает или выключает закрытие источника по завершению потока, в котором он создан.
//
// По умолчанию включено. Выключает тот, кто управляет временем жизни источника сам: контейнер
// приложения или код, создающий источник в одном потоке для работы в других. Тогда источник
// закрывается только явным Закрыть().
//
// Параметры:
//   Значение - Булево - Истина - закрывать по завершению потока; Ложь - только явным Закрыть().
//
Процедура УстановитьАвтоЗакрытие(Знач Значение) Экспорт
```
