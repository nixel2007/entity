## ИсточникДанных

Источник данных: имя, тип коннектора, строка соединения, параметры коннектора, размер пула
и сам пул соединений одним объектом.

Пул создается вместе с источником и общий для всех, кто работает через источник; соединения
пул открывает при первом обращении. Закрывает пул сам источник: методом `Закрыть()` или по
завершению потока, в котором источник создан, если автозакрытие не выключено, см.
`УстановитьАвтоЗакрытие`. Закрытие терминально: закрытый источник соединений больше не выдает,
поэтому любая операция через него завершается ошибкой. Тип коннектора и размер пула
проверяются при создании: тип без интерфейса `АбстрактныйКоннектор` и размер, не являющийся
неотрицательным числом, отвергаются с ошибкой.

```bsl
Источник = Новый ИсточникДанных("Основной", Тип("КоннекторPostgreSQL"), СтрокаСоединения, , 20);
Источник.ДобавитьНаблюдателя(Новый МойНаблюдатель);

МенеджерСущностей = Новый МенеджерСущностей(Источник);
```

Реестр наблюдателей общий у источника, его пула и всех менеджеров, созданных из него, см.
[Наблюдатели источника данных](Наблюдатели.md).

### ПриСозданииОбъекта

```bsl
// Параметры:
//   Имя - Строка - Имя источника данных.
//   ТипКоннектора - Тип - Тип класса, реализующего интерфейс АбстрактныйКоннектор.
//   СтрокаСоединения - Строка - Строка соединения с БД.
//   ПараметрыКоннектора - Массив - Дополнительные параметры коннектора.
//   РазмерПула - Число - Предел одновременно живущих соединений с БД. Ноль снимает предел
//     и постоянно живущих соединений не держит.
//
Процедура ПриСозданииОбъекта(
	Знач Имя,
	Знач ТипКоннектора,
	Знач СтрокаСоединения = "",
	Знач ПараметрыКоннектора = Неопределено,
	Знач РазмерПула = 10
)
```

### УстановитьАвтоЗакрытие

```bsl
// Включает или выключает закрытие источника по завершению потока, в котором он создан.
//
// По умолчанию включено. Выключает тот, кто управляет временем жизни источника сам: контейнер
// приложения или код, создающий источник в одном потоке для работы в других. Тогда источник
// закрывается только явным Закрыть().
//
// Параметры:
//   Значение - Булево - Истина - закрывать по завершению потока; Ложь - только явным Закрыть().
//
Процедура УстановитьАвтоЗакрытие(Знач Значение) Экспорт
```

### Закрыть

```bsl
// Закрывает пул соединений источника: все его соединения закрываются.
//
// Закрытие терминально: после него обращение через источник завершается ошибкой. Повторный
// вызов ничего не делает. Если закрытие завершилось ошибкой, источник закрытым не считается,
// и закрытие можно повторить: иначе оставшиеся соединения некому было бы закрыть.
//
```

### ДобавитьНаблюдателя

```bsl
// Регистрирует наблюдателя источника данных.
//
// Наблюдатель получает события всех операций, запросов, соединений и транзакций каждого
// менеджера, созданного из этого источника: самого менеджера, его хранилищ сущностей и
// Active Record. Реестр общий у источника и его менеджеров, поэтому регистрировать можно
// и после создания менеджера. См. интерфейс НаблюдательИсточникаДанных и класс
// СобытиеИсточникаДанных.
//
// Параметры:
//   Наблюдатель - Произвольный - Объект с аннотацией &Реализует("НаблюдательИсточникаДанных") на конструкторе,
//     реализующий этот интерфейс. Неполная реализация отвергается при регистрации.
//
// Пример:
//   Источник.ДобавитьНаблюдателя(Новый МойНаблюдатель);
//
Процедура ДобавитьНаблюдателя(Наблюдатель) Экспорт
```
