## ИсточникДанных

Описание источника данных: параметры соединения и пула одним объектом.

`ИсточникДанных` сам соединения не открывает; менеджер создается из источника и берет из него
тип коннектора, строку соединения, параметры коннектора и размер пула:

```bsl
Источник = Новый ИсточникДанных("Основной", Тип("КоннекторPostgreSQL"), СтрокаСоединения, , 20);

МенеджерСущностей = Новый МенеджерСущностей(Источник);
```

Конструктор менеджера по параметрам соединения устарел: он работает, но пишет предупреждение
в лог `oscript.lib.entity.manager`, как и лишние параметры, переданные вместе с источником.

### ПриСозданииОбъекта

```bsl
// Параметры:
//   Имя - Строка - Имя источника данных.
//   ТипКоннектора - Тип - Тип класса, реализующего интерфейс АбстрактныйКоннектор.
//   СтрокаСоединения - Строка - Строка соединения с БД.
//   ПараметрыКоннектора - Массив - Дополнительные параметры коннектора.
//   РазмерПула - Число - Размер пула соединений менеджера; по умолчанию тот же, что у
//     конструктора МенеджерСущностей. Ноль снимает предел и постоянно живущих соединений не держит.
//
Процедура ПриСозданииОбъекта(
	Знач Имя,
	Знач ТипКоннектора,
	Знач СтрокаСоединения = "",
	Знач ПараметрыКоннектора = Неопределено,
	Знач РазмерПула = 10
)
```
