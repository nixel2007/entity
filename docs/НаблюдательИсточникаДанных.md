## НаблюдательИсточникаДанных

Интерфейс наблюдателя источника данных.

Наблюдатель получает события источника данных, с которым работает менеджер сущностей:
операции (Сохранить, Получить, ПолучитьОдно, Удалить, Инициализировать, ВыполнитьСКоннектором,
ВычислитьСКоннектором), запросы к СУБД, захват и освобождение соединений, транзакции.
Каждое событие приходит дважды: до выполнения и после, одним и тем же объектом
[СобытиеИсточникаДанных](СобытиеИсточникаДанных.md).

Реализация объявляет интерфейс аннотацией `&Реализует("НаблюдательИсточникаДанных")` на конструкторе
и регистрируется на источнике данных методом `ДобавитьНаблюдателя`; менеджер, созданный из
источника, отдает ей события. Регистрация проверяет реализацию через `ВалидаторРеализации`
библиотеки extends, поэтому неполная реализация отвергается сразу.

Наблюдатель вызывается из разных потоков исполнения одновременно и не должен держать
несинхронизированного общего состояния: все, что нужно между фазами, кладется в событие
методом `УстановитьСостояние`; у каждого наблюдателя это состояние свое. Исключение наблюдателя
пишется в лог и операцию не прерывает.

Подробнее - в разделе [Наблюдатели источника данных](Наблюдатели.md).

```bsl
// Пример:
//   &Реализует("НаблюдательИсточникаДанных")
//   Процедура ПриСозданииОбъекта()
//   КонецПроцедуры
//
//   Процедура ПередСобытием(Событие) Экспорт
//       Событие.УстановитьСостояние(ТекущаяУниверсальнаяДатаВМиллисекундах());
//   КонецПроцедуры
//
//   Процедура ПослеСобытия(Событие) Экспорт
//       Сообщить(СтрШаблон("%1 %2: %3 мс", Событие.Вид(), Событие.Операция(), Событие.Длительность()));
//   КонецПроцедуры
//
&Интерфейс
Процедура ПриСозданииОбъекта()
```

### ПередСобытием

```bsl
// Вызывается перед выполнением события.
//
// Параметры:
//   Событие - СобытиеИсточникаДанных - Начатое событие. Поля результата обычно еще не заполнены;
//     у события, рассылка которого отложена, заполнены и они: см. Наблюдатели.md, раздел про
//     потоки исполнения.
//
Процедура ПередСобытием(Событие) Экспорт
```

### ПослеСобытия

```bsl
// Вызывается после выполнения события, в том числе завершившегося ошибкой.
//
// Параметры:
//   Событие - СобытиеИсточникаДанных - Завершенное событие: заполнены Длительность, Ошибка и поля результата.
//
Процедура ПослеСобытия(Событие) Экспорт
```
