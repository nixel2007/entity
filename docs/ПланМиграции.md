# ПланМиграции

План миграции схемы БД: упорядоченный набор изменений схемы, вычисленный
[МиграторомСхемы](МиграторСхемы.md) при сравнении модели данных с фактической схемой БД.
Элементами плана являются объекты [ИзменениеСхемы](ИзменениеСхемы.md).

### Добавить

```bsl
// Добавляет изменение схемы в план.
//
// Параметры:
//   ИзменениеСхемы - ИзменениеСхемы - Добавляемое изменение.
//
Процедура Добавить(Знач ИзменениеСхемы) Экспорт
```

### Изменения

```bsl
// Возвращает все изменения плана.
//
//  Возвращаемое значение:
//   Массив - Массив объектов ИзменениеСхемы.
//
Функция Изменения() Экспорт
```

### ИзмененияТаблицы

```bsl
// Возвращает изменения плана, относящиеся к переданной таблице.
//
// Параметры:
//   ИмяТаблицы - Строка - Имя таблицы.
//
//  Возвращаемое значение:
//   Массив - Массив объектов ИзменениеСхемы для таблицы.
//
Функция ИзмененияТаблицы(Знач ИмяТаблицы) Экспорт
```

### Пустой

```bsl
// Возвращает признак отсутствия изменений в плане.
//
//  Возвращаемое значение:
//   Булево - Истина, если план не содержит изменений.
//
Функция Пустой() Экспорт
```

### Количество

```bsl
// Возвращает количество изменений в плане.
//
//  Возвращаемое значение:
//   Число - Количество изменений.
//
Функция Количество() Экспорт
```

### Представление

```bsl
// Возвращает строковое представление плана для журналирования.
//
//  Возвращаемое значение:
//   Строка - Представление плана, по одному изменению на строку.
//
Функция Представление() Экспорт
```
