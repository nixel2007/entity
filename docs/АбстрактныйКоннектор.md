### ВТранзакции

Коннектор с транзакциями ведет признак сам: транзакцию может начать и бросить алгоритм
`ВыполнитьСКоннектором` мимо библиотеки, и узнать о ней пул может только у коннектора. Коннектор
без транзакций отвечает `Ложь`.

```bsl
// Определяет, начата ли этим коннектором транзакция, которая еще не завершена: методом
// коннектора или текстом запроса прямого доступа.
//
// По ответу пул откатывает транзакцию, брошенную алгоритмом ВыполнитьСКоннектором, прежде чем
// соединение достанется другому потоку исполнения. Коннектор без транзакций отвечает Ложь.
//
//  Возвращаемое значение:
//   Булево - Истина, если транзакция начата и не завершена.
//
Функция ВТранзакции() Экспорт
```

### ВыполнитьМонопольно

Библиотека поручает коннектору операции из нескольких запросов - сохранение сущности с
подчиненными таблицами: другие потоки не должны видеть их промежуточных состояний. Встроенные
коннекторы SQL выполняют действие в своей транзакции (внутри уже начатой - просто выполняют),
InMemory и JSON - под блокировкой записи базы или каталога, без отката. Коннектор, не умеющий
изолировать, просто выполняет действие.

```bsl
// Выполняет действие так, чтобы другие потоки исполнения не видели его промежуточных состояний.
//
// Параметры:
//   Действие - Действие - Действие без параметров.
//
Процедура ВыполнитьМонопольно(Действие) Экспорт
```

### НайтиСтрокиВТаблице

```bsl
// Осуществляет поиск строк в таблице по указанному отбору.
//
// Параметры:
//   ОбъектМодели - ОбъектМодели - Объект, содержащий описание класса-сущности и настроек таблицы БД.
//   ОпцииПоиска - ОпцииПоиска - Опции поиска. Содержит следующие параметры:
//     * Отборы - Массив - Отбор для поиска. Каждый элемент массива должен иметь тип "ЭлементОтбора".
//                         Каждый элемент отбора преобразуется к условию поиска.
//                         В качестве "ПутьКДанным" указываются имена колонок.
//     * Сортировки - Массив - Сортировка для результата поиска.
//                             Каждый элемент массива должен иметь тип "ЭлементПорядка".
//                             В качестве "ПутьКДанным" указываются имена колонок.
//
//  Возвращаемое значение:
//   Массив - Массив, элементами которого являются "Соответствия". Ключом элемента соответствия является имя колонки,
//     значением элемента соответствия - значение колонки.
//
Функция НайтиСтрокиВТаблице(ОбъектМодели, ОпцииПоиска) Экспорт
```
