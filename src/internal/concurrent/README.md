# concurrent

Служебные примитивы синхронизации. В публичный интерфейс entity не входят: подключаются по пути
`#Использовать "../internal/concurrent"`. Зависимостей от entity нет, поэтому каталог целиком
выносится в отдельную библиотеку без правок.

## БлокировкаЧтенияЗаписи

Реентерабельная блокировка чтения-записи. Читатели работают параллельно друг с другом, писатель — монопольно.

```bsl
Блокировка = Новый БлокировкаЧтенияЗаписи();

Блокировка.Чтение().Заблокировать();
Попытка
    // чтение ресурса
Исключение
    Блокировка.Чтение().Разблокировать();
    ВызватьИсключение;
КонецПопытки;
Блокировка.Чтение().Разблокировать();

Если Блокировка.Запись().ПопытатьсяЗаблокировать(1000) Тогда
    // изменение ресурса
    Блокировка.Запись().Разблокировать();
КонецЕсли;
```

Общий на процесс пул блокировок по ключу — модуль `БлокировкиЧтенияЗаписи`:

```bsl
Блокировка = БлокировкиЧтенияЗаписи.Получить(ИмяФайла);
```

### Владелец блокировки

Владельцем считается контекст исполнения, а не поток операционной системы: фоновое задание опознаётся по `ФоновыеЗадания.ПолучитьТекущее()`, а весь код вне фоновых заданий считается одним владельцем. Отсюда два ограничения:

* код, запущенный в потоках в обход `ФоновыеЗадания`, между собой не различается;
* `ФоновыеЗадания.Очистить()` очищает список заданий, после чего работающее задание перестаёт опознаваться и сливается с кодом вне заданий.

### Реентерабельность

Контекст, уже владеющий блокировкой, захватывает её повторно без ожидания. Каждому захвату должно соответствовать освобождение.

Владелец блокировки записи может захватить чтение. Обратный переход — повышение чтения до записи — не поддерживается и вызывает исключение: два читателя, одновременно запросившие запись, ждали бы освобождения друг друга.

### Приоритет писателя

Пока писатель ожидает, новые читатели не допускаются — иначе поток читателей вытеснял бы запись. Повторный захват чтения владельцем при этом не ждёт, иначе вложенное чтение блокировало бы само себя.

```bsl
Функция Запись() Экспорт
```

### Методы половины блокировки

Обе половины — `БлокировкаЧтения` и `БлокировкаЗаписи` — имеют одинаковый набор методов.

```bsl
// Захватить блокировку, ожидая освобождения сколько потребуется.
//
Процедура Заблокировать() Экспорт

// Попытаться захватить блокировку.
//
// Параметры:
//   ТаймаутОжидания - Число - Предельное время ожидания в миллисекундах.
//                   - Неопределено - Одна попытка без ожидания.
//
// Возвращаемое значение:
//   Булево - Истина, если блокировка захвачена. Ложь означает, что ресурс занят, и освобождать
//            блокировку не нужно.
//
Функция ПопытатьсяЗаблокировать(Знач ТаймаутОжидания = Неопределено) Экспорт

// Освободить блокировку.
//
Процедура Разблокировать() Экспорт
```
